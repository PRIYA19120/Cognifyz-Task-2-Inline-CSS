# Cognifyz Task 2 - Styling with Inline CSS

## About the Project
This project is part of my Front-End Development Internship at Cognifyz Technologies.

## Objective
To understand the fundamentals of CSS by applying styles directly to HTML elements.

## Features
- Different font colors and sizes
- Background color styling
- Inline CSS applied to headings and paragraphs
- Styled content card with padding and rounded corners

## Technologies Used
- HTML5
- Inline CSS

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Learning Outcome
I learned how to use inline CSS to customize the appearance of HTML elements.
